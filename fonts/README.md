# Fonts

- `SourceSansPro-*.ttf` — Source Sans Pro by Adobe, licensed under the SIL Open Font License 1.1 (https://scripts.sil.org/OFL). Free to bundle and serve.
- **Publico** (brand headline font) is a commercial font and is intentionally **not** stored here: this repository is public.
  The app uses Publico only when it is installed on the viewer's computer (`local()`), and falls back to Source Serif 4 (Google Fonts, OFL).
  If the company's Publico licence covers web embedding on a private server, the files can be added later.
