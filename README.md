# Agency Experience Team Hub

ระบบกลางสำหรับวางแผนและติดตามงานของทีม Agency Experience — **บันทึกงานครั้งเดียว ดูได้หลายมุม**
(Home · My Plan · Projects · Calendar · Board (Gantt/Kanban) · Offsite · Poster · Team · AI Meeting Hub (ปิดไว้ชั่วคราว — เปิดได้ที่ `FEATURES.meetings` ใน js/app.js) · ทีมและสิทธิ์)

## เริ่มใช้งาน
```bash
node server.js        # เปิด http://localhost:3000 — ข้อมูลใช้ร่วมกันทั้งทีม (เก็บใน data/state.json)
```
หรือเปิด `index.html` / host เป็น static site ก็ได้ — ข้อมูลจะเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น (ไม่แชร์ข้ามคน)

## Deploy บน Vercel (GitHub → Vercel)
1. Merge branch นี้เข้า `main` ของ repo แล้ว Import repo ใน Vercel (Framework: **Other**, ไม่ต้องมี Build Command, Output = root)
2. ใน Vercel โปรเจกต์ → **Storage → Create / Marketplace → Upstash Redis** → เชื่อมกับโปรเจกต์ (ระบบใส่ `KV_REST_API_URL` และ `KV_REST_API_TOKEN` ให้อัตโนมัติ)
3. (แนะนำ) ตั้ง Environment Variable `HUB_DEFAULT_PASSWORD` = รหัสเริ่มต้นของทุกคน (ถ้าไม่ตั้ง ระบบสร้างให้และแสดงครั้งเดียวบนหน้า Login ของคนแรกที่เปิด)
4. Redeploy → เปิดเว็บ → เข้าเป็น **Kaeng (Admin)** → Team → เปลี่ยนรหัสเริ่มต้น/ตั้งรหัสรายบุคคล และตั้งสายบังคับบัญชา
- ไฟล์แนบในโหมดนี้จำกัด 300 KB/ไฟล์ (ไฟล์ใหญ่ให้ใส่ Link) · แอปตรวจข้อมูลใหม่ทุก 60 วินาทีเฉพาะตอนเปิดหน้าไว้ เพื่อประหยัดโควตาฐานข้อมูล
- ทดสอบในเครื่องโดยไม่ใช้ Vercel: `node server.js` (เก็บข้อมูลใน `data/`)

## กู้รหัส Admin (ลืมรหัส)
1. ใน Vercel → Settings → Environment Variables เพิ่ม `HUB_RECOVERY_CODE` = ข้อความลับยาวอย่างน้อย 8 ตัว → Redeploy
2. หน้า Login จะมีลิงก์ “ลืมรหัส Admin?” → เลือกบัญชี Admin ใส่รหัสกู้คืน + รหัสผ่านใหม่
3. รหัสกู้คืนแต่ละค่าใช้ได้ **ครั้งเดียว** (ใช้แล้วต้องเปลี่ยนค่าใหม่ถึงจะใช้อีก) · กู้ได้เฉพาะบัญชี Admin · เครื่องที่ล็อกอินค้างของบัญชีนั้นจะถูกบังคับออกจากระบบ · เสร็จแล้วควรลบตัวแปรนี้ออก
- ใครเข้าถึงบัญชี Vercel ได้ก็ตั้งตัวแปรนี้ได้ จึงควรเปิด 2-step verification ให้บัญชี Vercel/GitHub/Upstash

## การเข้าสู่ระบบ
- เลือกชื่อ + ใส่รหัสผ่าน · Admin ตั้งรหัสเริ่มต้น/รายบุคคลที่ Team · สมาชิกเปลี่ยนรหัสเองที่ “Account” · Admin เห็นรหัสของทุกคน (ตั้งใจให้เป็นแบบนี้ เพื่อช่วยคนลืมรหัส)
- `node server.js` = ล็อกอินจริง (เซิร์ฟเวอร์ตรวจ token ทุก request, เก็บรหัสใน `data/auth.json` แบบ plain text — ต้องเก็บโฟลเดอร์ data เป็นความลับและใช้ HTTPS) · รหัสเริ่มต้นแสดงใน terminal ตอนเปิดเซิร์ฟเวอร์ครั้งแรก
- เปิดเป็น static (เช่น Vercel/GitHub Pages) = โหมดสาธิต: ข้อมูลและรหัสอยู่ในเบราว์เซอร์ของแต่ละคน ไม่แชร์และไม่ปลอดภัยจริง

## หมายเหตุสำคัญ
- **ผู้ใช้/สิทธิ์เป็นโหมดสาธิต** (เลือกชื่อเอง) — ใช้งานจริงควรใส่ระบบล็อกอิน (SSO) หน้า server
- Sync เป็นแบบ whole-state, last-write-wins — เหมาะกับทีมเล็ก ไม่ใช่ฐานข้อมูลหลายผู้ใช้เต็มรูปแบบ
- **AI Meeting Hub** ใช้กฎอ่านข้อความในเครื่อง (`analyzeMeeting` ใน `js/views-c.js`) — ไฟล์เสียงและรูป Post-it ถูกแนบแต่ยังไม่ถอดความอัตโนมัติ; เปลี่ยนฟังก์ชันนี้ไปเรียก AI/Speech-to-text ได้ ผลลัพธ์เป็นฉบับร่างที่ต้องตรวจก่อนสร้าง Task เสมอ
- Export: Excel = ไฟล์ CSV, PDF = ปุ่ม “พิมพ์ / PDF”
- ไฟล์แนบเก็บในข้อมูลโดยตรง (≤ 1 MB/ไฟล์) — ไฟล์ใหญ่ให้ใส่เป็น Link
- วันหยุดบริษัทตัวอย่างปรับได้ที่ ทีมและการตั้งค่า (Admin)

## Poster — CI Poster Builder
สร้าง Communications Poster เองได้เร็ว บน Template มาตรฐานและ CI องค์กร (เมนู **Poster**)
1. เลือก Template — Announcement · Event & Invitation · Campaign · How-to & Tips · Recognition — และขนาด Square 1:1 (1080×1080) · Portrait 4:5 (1080×1350) · Story 9:16 (1080×1920, เว้นขอบบน/ล่างให้ UI ของแอป) · Landscape 16:9 (1920×1080)
2. กรอก Keyword, Headline, Content (ขึ้นบรรทัดใหม่ = 1 ข้อ / 1 ขั้นตอน), Call to action และรายละเอียดเพิ่มเติม: วัน เวลา สถานที่ QR Code (จากลิงก์ หรืออัปโหลดรูป QR) เงื่อนไข
3. **เรียบเรียงด้วย AI** (`POST /api/ai-poster`, ใช้ `ANTHROPIC_API_KEY` เดียวกับ AI Import) — ปรับถ้อยคำ จัดลำดับ เลือกไอคอน ลายกราฟิก และสีเน้นจาก CI; วัน เวลา สถานที่ และเงื่อนไขไม่ถูกส่งให้แก้ และระบบตรวจตัวเลขซ้ำ (ตัวเลขหาย / มีตัวเลขใหม่ → แจ้งเตือน + ปุ่มย้อนกลับ) · ไม่มี Key หรือโหมดสาธิต → ใช้ “จัดอัตโนมัติ” แทน
4. Preview สด ปรับพื้นหลัง สีเน้น รูปประกอบ ลายกราฟิก ไอคอนได้ · เปลี่ยนขนาดจากงานเดิมได้ทันที ระบบจัดข้อความ/ภาพใหม่และย่อขนาดตัวอักษรให้พอดีเอง
5. Export PNG / JPG หรือครบ 4 ขนาด — ต้องติ๊ก “ตรวจสอบแล้ว” ใหม่ทุกครั้งที่แก้ไข
- **CI Control** (Admin): ชื่อองค์กร ข้อความท้ายโปสเตอร์ โลโก้ (พื้นสว่าง/พื้นเข้ม) และสีที่อนุมัติ — เก็บใน `settings.brand` ใช้ร่วมกันทั้งทีม · ฟอนต์ล็อก: Publico (ถ้าติดตั้ง) / Source Serif 4 · Source Sans Pro · IBM Plex Sans Thai
- ฉบับร่างเก็บในเบราว์เซอร์ของแต่ละคน (ล่าสุด 20 งาน)
- QR Code: `js/vendor/qrcode.min.js` — qrcode-generator โดย Kazuhiko Arase (MIT)
