# Agency Experience Team Hub

ระบบกลางสำหรับวางแผนและติดตามงานของทีม Agency Experience — **บันทึกงานครั้งเดียว ดูได้หลายมุม**
(Home · My Plan · Projects · Calendar · Board (Gantt/Kanban) · Offsite · Poster · Team · AI Meeting Hub (ปิดไว้ชั่วคราว — เปิดได้ที่ `FEATURES.meetings` ใน js/app.js) · ทีมและสิทธิ์)

## เริ่มใช้งาน
```bash
node server.js        # เปิด http://localhost:3000 — ข้อมูลใช้ร่วมกันทั้งทีม (เก็บใน data/state.json)
```
หรือเปิด `index.html` / host เป็น static site ก็ได้ — ข้อมูลจะเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น (ไม่แชร์ข้ามคน)

## Deploy บน Vercel (GitHub → Vercel)
1. Merge branch นี้เข้า `main` ของ repo แล้ว Import repo ใน Vercel (Framework: **Other**, ไม่ต้องมี Build Command, Output = root)
2. ใน Vercel โปรเจกต์ → **Storage → Create / Marketplace → Upstash Redis** → เชื่อมกับโปรเจกต์ (ระบบใส่ `KV_REST_API_URL` และ `KV_REST_API_TOKEN` ให้อัตโนมัติ)
3. (แนะนำ) ตั้ง Environment Variable `HUB_DEFAULT_PASSWORD` = รหัสเริ่มต้นของทุกคน (ถ้าไม่ตั้ง ระบบสร้างให้และแสดงครั้งเดียวบนหน้า Login ของคนแรกที่เปิด)
4. Redeploy → เปิดเว็บ → เข้าเป็น **Kaeng (Admin)** → Team → เปลี่ยนรหัสเริ่มต้น/ตั้งรหัสรายบุคคล และตั้งสายบังคับบัญชา
- ไฟล์แนบในโหมดนี้จำกัด 300 KB/ไฟล์ (ไฟล์ใหญ่ให้ใส่ Link) · แอปตรวจข้อมูลใหม่ทุก 60 วินาทีเฉพาะตอนเปิดหน้าไว้ เพื่อประหยัดโควตาฐานข้อมูล
- ทดสอบในเครื่องโดยไม่ใช้ Vercel: `node server.js` (เก็บข้อมูลใน `data/`)

## กู้รหัส Admin (ลืมรหัส)
1. ใน Vercel → Settings → Environment Variables เพิ่ม `HUB_RECOVERY_CODE` = ข้อความลับยาวอย่างน้อย 8 ตัว → Redeploy
2. หน้า Login จะมีลิงก์ “ลืมรหัส Admin?” → เลือกบัญชี Admin ใส่รหัสกู้คืน + รหัสผ่านใหม่
3. รหัสกู้คืนแต่ละค่าใช้ได้ **ครั้งเดียว** (ใช้แล้วต้องเปลี่ยนค่าใหม่ถึงจะใช้อีก) · กู้ได้เฉพาะบัญชี Admin · เครื่องที่ล็อกอินค้างของบัญชีนั้นจะถูกบังคับออกจากระบบ · เสร็จแล้วควรลบตัวแปรนี้ออก
- ใครเข้าถึงบัญชี Vercel ได้ก็ตั้งตัวแปรนี้ได้ จึงควรเปิด 2-step verification ให้บัญชี Vercel/GitHub/Upstash

## การเข้าสู่ระบบ
- เลือกชื่อ + ใส่รหัสผ่าน · Admin ตั้งรหัสเริ่มต้น/รายบุคคลที่ Team · สมาชิกเปลี่ยนรหัสเองที่ “Account” · Admin เห็นรหัสของทุกคน (ตั้งใจให้เป็นแบบนี้ เพื่อช่วยคนลืมรหัส)
- `node server.js` = ล็อกอินจริง (เซิร์ฟเวอร์ตรวจ token ทุก request, เก็บรหัสใน `data/auth.json` แบบ plain text — ต้องเก็บโฟลเดอร์ data เป็นความลับและใช้ HTTPS) · รหัสเริ่มต้นแสดงใน terminal ตอนเปิดเซิร์ฟเวอร์ครั้งแรก
- เปิดเป็น static (เช่น Vercel/GitHub Pages) = โหมดสาธิต: ข้อมูลและรหัสอยู่ในเบราว์เซอร์ของแต่ละคน ไม่แชร์และไม่ปลอดภัยจริง

## หมายเหตุสำคัญ
- **ผู้ใช้/สิทธิ์เป็นโหมดสาธิต** (เลือกชื่อเอง) — ใช้งานจริงควรใส่ระบบล็อกอิน (SSO) หน้า server
- Sync เป็นแบบ whole-state, last-write-wins — เหมาะกับทีมเล็ก ไม่ใช่ฐานข้อมูลหลายผู้ใช้เต็มรูปแบบ
- **AI Meeting Hub** ใช้กฎอ่านข้อความในเครื่อง (`analyzeMeeting` ใน `js/views-c.js`) — ไฟล์เสียงและรูป Post-it ถูกแนบแต่ยังไม่ถอดความอัตโนมัติ; เปลี่ยนฟังก์ชันนี้ไปเรียก AI/Speech-to-text ได้ ผลลัพธ์เป็นฉบับร่างที่ต้องตรวจก่อนสร้าง Task เสมอ
- Export: Excel = ไฟล์ CSV, PDF = ปุ่ม “พิมพ์ / PDF”
- ไฟล์แนบเก็บในข้อมูลโดยตรง (≤ 1 MB/ไฟล์) — ไฟล์ใหญ่ให้ใส่เป็น Link
- วันหยุดบริษัทตัวอย่างปรับได้ที่ ทีมและการตั้งค่า (Admin)

## Weekly Update — Management weekly update (Admin)
- เมนู **Weekly Update** ใช้ได้เฉพาะ Admin ทั้งหน้าจอและ API
- กด **ให้ AI สรุปงาน** เพื่อเรียบเรียง bullet points ตามกลุ่มหน้าที่ทีม เช่น Event, Creative, Multimedia และ Communication: ความคืบหน้าสัปดาห์นี้ แผนสัปดาห์หน้า และประเด็นติดตาม
- ใช้สัปดาห์จันทร์–อาทิตย์ตามเวลาประเทศไทย รวมงานค้างและงานที่ปิดในสัปดาห์นี้ ไม่รวมงาน “เฉพาะฉัน” หรืองานยกเลิก งานสองผู้รับผิดชอบนับครั้งเดียวตามกลุ่มหน้าที่ของผู้รับผิดชอบหลัก
- เลือกภาษาไทย / English และ **คัดลอกสรุป** เพื่อนำไปใช้ต่อได้ ตรวจข้อเท็จจริงในฉบับร่างก่อนส่ง
- ใช้การเชื่อม Gemini / Claude ที่ Admin ตั้งไว้ใน **Poster → CI Control** ข้อมูลมาจากงานที่บันทึกแล้วใน My Plan และ Projects; โหมดสาธิตไม่เรียก AI
- ทดสอบช่วงวันที่ สิทธิ์ API และการเรียก AI แบบจำลอง: `npm test`

## Poster — CI Poster Builder
สร้าง Communications Poster เองได้เร็ว บน Template มาตรฐานและ CI องค์กร (เมนู **Poster**) — ภาษาภาพตามแนวทาง Health Content Education 2026
1. เลือก Template — Announcement · Event & Invitation · Campaign · How-to & Tips · Recognition — และขนาด Square 1:1 (1080×1080) · Portrait 4:5 (1080×1350) · Story 9:16 (1080×1920, เว้นขอบบน/ล่างให้ UI ของแอป) · Landscape 16:9 (1920×1080)
2. กรอก Keyword, Headline (บรรทัดแรก = แถบเน้น · Enter = บรรทัดตัวใหญ่ต่อ), Content (ขึ้นบรรทัดใหม่ = 1 ข้อ / 1 ขั้นตอน), Call to action และรายละเอียดเพิ่มเติม: วัน เวลา สถานที่ QR Code (จากลิงก์ หรืออัปโหลดรูป QR) เงื่อนไข
3. ภาพประกอบตามเนื้อหา: ระบบเลือก “ฉาก” (สุขภาพ วัคซีน โรงพยาบาล/เคลม ปรึกษาแพทย์ แอป ยา ความคุ้มครอง ครอบครัว ค่าใช้จ่าย ระยะเวลา ขั้นตอน งาน รางวัล แคมเปญ เดินทาง หน้าฝน PM 2.5 ประกาศ) จากคำในเนื้อหาให้อัตโนมัติ **โดยไม่ใช้ AI** · อัปโหลดรูปคน/สถานที่ → แสดงเต็มพื้นหลังพร้อมเงาสีน้ำเงินด้านข้อความ
   - **เรียบเรียงข้อความ + ออกแบบ** (`POST /api/ai-poster`) — ปรับถ้อยคำ จัดลำดับ และเลือกฉาก ไอคอน 3 ตัว พื้นหลัง สีเน้น; วัน เวลา สถานที่ เงื่อนไขไม่ถูกแก้ และตรวจตัวเลขซ้ำ (หาย / เพิ่ม → แจ้งเตือน + ย้อนกลับ)
   - **ให้ AI ออกแบบภาพอย่างเดียว** (`POST /api/ai-design`) — ส่งแค่ข้อความสั้น ≤ 600 ตัวอักษร ใช้ Claude Haiku 5.5 (effort low) ตอบเป็นตัวเลือกจากรายการ CI และจำผลไว้ ข้อความเดิมไม่เรียกซ้ำ
   - ใช้ `ANTHROPIC_API_KEY` เดียวกับ AI Import · ไม่มี Key หรือโหมดสาธิต → ใช้การเลือกอัตโนมัติแทน
4. Preview สด ปรับพื้นหลัง (Deep Blue · Lavender · Light Blue · Soft Pink · White · Photo) สีเน้น ภาพประกอบ ไอคอนหลัก · เปลี่ยนขนาดจากงานเดิมได้ทันที ระบบจัดใหม่และย่อตัวอักษรให้พอดีเอง (ภาพประกอบหดก่อนตัวอักษร)
5. Export PNG / JPG หรือครบ 4 ขนาด — ต้องติ๊ก “ตรวจสอบแล้ว” ใหม่ทุกครั้งที่แก้ไข
- **CI Control** (Admin): โลโก้คู่ Krungthai-AXA มุมซ้ายบน (ไฟล์สีสำหรับพื้นสว่าง + ไฟล์ขาว/ขอบขาวสำหรับพื้นเข้มและรูป รับ SVG/PNG — อัปโหลดไฟล์ทางการจากทีม Brand; repo นี้ไม่เก็บไฟล์โลโก้) สีที่อนุมัติ (ค่าเริ่มต้นตามไฟล์ Logo_Font_CI_Guidelines: AXA Blue #00008F · AXA Red #FF1721 · Blue Tint 1/2/3 #E2EFFF/#6574F8/#0C0E45 · Red Tint 1 #FFEAEA) ชื่อองค์กร และข้อความกำกับท้าย — เก็บใน `settings.brand` ใช้ร่วมกันทั้งทีม
- ฉบับร่างเก็บในเบราว์เซอร์ของแต่ละคน (ล่าสุด 20 งาน)
- QR Code: `js/vendor/qrcode.min.js` — qrcode-generator โดย Kazuhiko Arase (MIT)

## PR Master

Admin เปิด **PR Master** ใน TEAM Hub เพื่อพิมพ์บรีฟ แนบรูปบุคคล และสร้างโปสเตอร์ **Prime Clinic / Event Invitation** หรือ **Prime Recognition** แบบเน้นรูปและแบบเน้นหัวเรื่อง ขนาด 4:5 และ 1:1 แก้ชื่อ วัน เวลา สถานที่ CTA และครอปภาพได้ก่อนดาวน์โหลด PNG/JPG หรือเปิดเป็นเลเยอร์ใน Poster Studio

- **นำเข้าบรีฟจาก PowerPoint** รองรับไฟล์ .pptx ไม่เกิน 20 MB เลือกสไลด์และรูปที่ฝังอยู่ในสไลด์ ข้อความและรูปถูกอ่านในเบราว์เซอร์ จากนั้นระบบส่งเฉพาะข้อความบรีฟให้ AI เดิมเมื่อเปิดใช้ AI รุ่นนี้อ่านกล่องข้อความและรูป JPEG/PNG/WebP โดยไม่ได้ถอดข้อความที่ฝังอยู่ในภาพ
- ใช้การเชื่อม Gemini/Claude เดิมใน **Poster → CI Control** หาก AI ไม่พร้อม ระบบจัดวางจากบรีฟและให้แก้ข้อมูลเองได้ บรีฟหลายบรรทัดใส่หัวข้อกำกับได้ เช่น `วิทยากร:` และ `วันที่:`
- ใช้โลโก้ Krungthai-AXA และ AXA Prime จากชุดแบรนด์เดิม รวมถึง Publico, Source Sans Pro และ DB Helvethaica X ตาม CI ให้ Admin ติดตั้งหรืออัปโหลดฟอนต์ที่องค์กรมีสิทธิ์ใช้ผ่าน CI Control เมื่อข้อมูลหรือ CI ยังมีจุดที่ต้องตรวจ ระบบให้ดาวน์โหลดฉบับร่างที่มีป้าย DRAFT
- ปุ่ม **ตัดพื้นหลังใน Adobe Express** เปิดเครื่องมือของ Adobe ในแท็บใหม่ ให้ดาวน์โหลด PNG โปร่งใสแล้วแนบกลับใน PR Master ระบบตรวจความโปร่งใสและจัดวางบุคคลโดยรักษาสัดส่วนให้อัตโนมัติ
- เปิดการตัดพื้นหลังอัตโนมัติด้วย Photoshop API v2 โดยตั้งค่า `PR_ADOBE_CLIENT_ID` และ `PR_ADOBE_CLIENT_SECRET` จาก Adobe Developer Console และ `PR_MASTER_PUBLIC_ORIGIN` เป็น origin HTTPS ของ TEAM Hub ที่ Adobe เข้าถึงได้ เช่น `https://team-hub.example.com` เส้นทาง `/api/pr-photo/…` ใช้ลิงก์ลงลายเซ็นอายุสั้นสำหรับรับส่งรูปชั่วคราว ระหว่างงานบน Vercel ใช้ Upstash เดิมพร้อม TTL หาก Adobe ไม่พร้อมหรือประมวลผลล้มเหลว แอปใช้รูปต้นฉบับ
- รูปจากเครื่องและรูปตัดพื้นหลังอยู่ในแท็บที่กำลังทำงาน ภาพจะต้องแนบใหม่เมื่อเปิดฉบับร่างที่บันทึกไว้หลังรีโหลดเว็บ
